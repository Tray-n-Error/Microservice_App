### guided project from a "Let's Get Rusty Bootcamp"
# Microservice_App
An example project to learn about microservices and gain some experience with Docker and Http-requests. Basically there is a client which can sign-up, sign-in and sign-out users.

It is created as a mono-repo, consisting of 3 seperate projects: "auth-service", "client" and "health-check-service"
